Named Rules
The One Accent Rule
Ops Amber is the only saturated color in the interface outside of status indicators. If more than 10% of a screen surface is amber, reduce usage until it reads as signal, not decoration.
The Tinted Neutral Rule
Every neutral carries a warm hue tint (chroma 0.001-0.011, hue 48-106). Never use pure gray, #000, or #fff. The warmth is subtle but essential to cohesion.
The Flat Formation Rule
If an element is in the page flow, it is flat. Shadows are exclusively for elements that break the page plane: popovers, dialogs, dropdowns. A card with a shadow is a bug.
The Three Voices Rule
Every text element uses exactly one of three font families. Barlow Condensed for structure. Source Serif 4 for content. IBM Plex Mono for data. No mixing.
Do
Use OKLCH for all colors. Use the three-font system consistently. Keep transitions 120-240ms with exponential ease-out. Respect prefers-reduced-motion. Use tinted backgrounds for status colors. Cap body text at 65-75ch.
Don't
No pastel gradients, playful illustrations, or bouncy animations. No green-on-gray schemes or 12px system fonts. No shadows on in-flow elements. No #000, #fff, or achromatic neutrals. No second accent color. No gradient text or glassmorphism.
