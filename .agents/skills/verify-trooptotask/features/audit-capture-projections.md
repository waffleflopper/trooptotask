# Audit capture and safe projections

Organization owners inspect their own activity summaries; platform super-admins investigate saved events across Organizations without disclosing those privileged details to other roles.

## Sub-features

- `capture`: a real producer's event keeps its meaning, actor, Organization and resource references; risky freeform details and unauthenticated email identifiers are masked before storage.
- `organization-log`: owner-only summaries, newest-first ordering, search, sorting, 25-row client pages over the latest 100 loaded records, counts and reload.
- `safe-labels`: authorized page data resolves only same-Organization Personnel, Training and Calendar labels, preserves saved masked values and strips remaining top-level string UUID details.
- `platform-log`: super-admin-only full records, stored details, server paging and action/severity/Organization filters; support's recent User/Organization activity projections remain reduced.
- `denial-and-recovery`: admin/member/foreign denial, failed page navigation and retry, and target changes without cross-Organization disclosure.

## How to get to it (user POV)

As an Organization owner, open Settings and Logs. Search or sort the table and use its paging controls. The screen intentionally shows summaries (Time, Area, Event and Actor), rather than event details. As a platform super-admin, open Admin and Audit Log; filter events, navigate pages and open a row's `View` disclosure. Organization administrators and platform support do not have full Audit Log admission.

## Gotchas

- Organization Logs is owner-only despite the broader Settings shell admitting administrators. Support's Feedback access does not grant full Platform Audit access.
- Audit display enrichment is not a second sanitizer. Historical raw saved details are not retroactively masked by either query; synthetic raw-secret inserts cannot be counted as producer masking tests.
- Stripping applies to top-level string UUID detail values. It does not remove event identity, resource/user references or platform raw saved details, and does not promise recursive removal.
- Organization summaries use client pages over a bounded latest-100 load; Platform Audit uses server pages of 50.
- Native select filling matches visible option text. Use keyboard selection/deletion to clear search or Notes when an empty `fill` does not fire an input event. Verify Logs is actually keyboard-focused before arming its failure; same-route navigation can reset focus.
- Existing `auditLogQuery`, writer, platform service/adapter, settings route and admin adapter tests retain separate behavioral/security obligations. The timestamp-index SQL test proves its index only. Do not run cleanup jobs merely to prove audit reads.
