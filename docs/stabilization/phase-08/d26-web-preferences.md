It groups #1420's preference-triggered workspace reload, lost visible intent during navigation and stale feedback under the same state/lifetime repair. No migration is planned.

Acceptance requires immediate visible filtering, debounced serial persistence, latest local intent over older acknowledgements, visible active-save failure and explicit retry, same-Organization navigation without resetting choices, and retirement of pending work/feedback when the user or Organization changes.
