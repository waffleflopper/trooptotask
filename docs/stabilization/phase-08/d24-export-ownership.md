Export state and presentation move behind Data Export's consumed Web seam; canonical-Organization keyed lifetimes remain in Delivery. Archives and Data Export both consume the relocated neutral Blob helper with identical cleanup semantics. Shared workbook utilities and all source owners' normal/report/retention consumers remain supported.

The throughput checkpoint preserves the existing twelve-read cap and complete provider traversal. It avoids another scheduler, serial source bundles, browser-to-own-API loops or privileged basic Personnel reads. Root owns integration, application proof and publication.
