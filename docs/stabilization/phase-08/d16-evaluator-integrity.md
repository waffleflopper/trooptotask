## Declared repair outcome

Reject new or changed foreign/missing internal rater, senior rater, intermediate rater and reviewer IDs before application mutation, and enforce Organization integrity for direct/provider writes. Keep the rated Person as the existing Group authorization anchor. Allow local archived, cross-Group and unassigned evaluators; retain external names/nulls and saved history. Compare changed IDs with the existing entry read and validate at most four IDs in one bounded Personnel-owned existence lookup. UUID case and duplicate references represent the same Person. Unchanged historical invalid links stay editable; the repair does not silently normalize or rewrite them.

The [migration](../../../supabase/migrations/20260930000100_rating_scheme_evaluator_integrity.sql) adds NOT VALID composite Organization/evaluator references and replaces global SET NULL effects with deferred ID guards, following the integrated Personnel Group repair. On evaluations without invalid historical links, Person deletion clears only the local evaluator columns, preserving evaluation identity and other data (the normal update timestamp may change). A historical foreign link blocks and rolls back deletion of that foreign Person, preventing changes in another Organization or an orphan. **A mixed legacy evaluation can also block deletion of a local Person:** multiple SET NULL actions can recheck an untouched foreign slot. The entire statement/transaction is rolled back, including local clears and rated cascades. This conservative constraint-only behavior preserves history; correcting it requires explicit, separately reviewed operator choices, not an automatic migration rewrite or a bespoke bypass trigger. Rated-Person cascade remains the existing behavior for otherwise valid deletion.

```sql
BEGIN TRANSACTION READ ONLY;
SET LOCAL row_security = off;
SELECT slot, count(*) FILTER (WHERE p.id IS NULL) AS missing,
  count(*) FILTER (WHERE p.id IS NOT NULL AND p.organization_id <> e.organization_id) AS foreign_org
FROM public.rating_scheme_entries e
CROSS JOIN LATERAL (VALUES
  ('rater', e.rater_person_id), ('senior_rater', e.senior_rater_person_id),
  ('intermediate_rater', e.intermediate_rater_person_id), ('reviewer', e.reviewer_person_id)
) AS refs(slot, person_id)
LEFT JOIN public.personnel p ON p.id = refs.person_id
WHERE refs.person_id IS NOT NULL
GROUP BY slot ORDER BY slot;
ROLLBACK;
```
