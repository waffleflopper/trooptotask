# Domain Docs

This is a single-context repo. Use [CONTEXT.md](../../CONTEXT.md) for the business rules involved in the task and its [Language section](../../CONTEXT.md#language) for names in code, tests, docs and product copy.

For an architectural decision, consult the [ADR index](../architecture/ADR_INDEX.md) and read only the relevant ADRs. Boundary changes use the [architecture reading map](architecture-governance.md).

Keep canonical Organization/Group terminology. If a term or reference is missing, search the existing context and record the gap; continue work whose behavior is already established. Ask only when the missing definition or an ADR conflict affects a consequential decision required for the task, following the [operating model](../architecture/AI_AGENT_OPERATING_MODEL.md#decision-boundaries).
