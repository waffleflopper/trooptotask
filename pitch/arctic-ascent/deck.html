Security · access

Built to maximize security.

  • Scoped access, enforced by the server. Organization-wide or by Group, set per feature: none, view, operate or configure. Only see what they need to know.
  • Viewer, Operator and Editor presets, with per-feature overrides. Archive and delete requests need approval so a bad actor can't wreak havoc.
  • Separate Organizations. One account can switch between units, and their data never mixes.
  • Encrypted in transit (TLS 1.2+) and at rest (AES-256). Files open through 5-minute private links.
  • 2FA, Password complexity requirements, and a re-verification for sensitive actions. Audit log kept for a year.
  • Aligned with NIST 800-171 on SOC 2 Type II hosting. FedRAMP is the next step.
